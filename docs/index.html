nanoMuseAn open-source personal agent for every device you own.

One agent with a name and a face. It does things, keeps going when the app is closed, remembers you, and asks before anything you could not undo. The whole set — phone, desktop, web, relay — is in one repository, and the same code runs on a server of yours.
