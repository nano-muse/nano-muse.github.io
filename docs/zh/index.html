在手机、电脑和网页上使用同一个开源智能体。

用一个账号连接你的设备，让 nanoMuse 帮你执行任务。关闭 App 后，它仍可继续处理任务；它的记忆保存在你能阅读的文件中，执行不可撤销的操作前会征求你的同意。项目的全部代码都在同一个仓库中，采用 GPL-3.0-or-later 许可证。负责登录和设备通信的中继服务也可以部署在你自己的服务器上。

智能体（agent）是能调用工具、执行任务的 AI 程序。中继（relay）负责账号登录和设备之间的通信。文档里的其他技术名词可查阅术语表。

选择安装方式 ​

浏览器打开 demo.nanomuse.dev 并登录，即可在模拟手机上体验 nanoMuse。页面提供可点击的中英文任务示例。此页面用于演示，日常使用请安装下面的 App
Android 8.0 及以上，arm64nanoMuse-1.0.10-arm64.apk · 安装说明
iPhone / iPad通过 TestFlight 安装。TestFlight 是 Apple 分发测试版 App 的工具，此版本已通过 Apple 的测试版审核 · iOS 使用说明
macOS 12 及以上Apple 芯片 · Intel 芯片 · 桌面版使用说明
Windows 10 以上nanoMuse-Desktop-1.0.10-win-x64.exe
Linux x64AppImage · .deb · tar.gz
Docker用 bash scripts/self-host.sh --local 部署自己的中继，用 docker compose up -d app 运行网页版。Docker 用容器封装程序及其运行环境 · 部署说明

参与改进 nanoMuse

nanoMuse 提供开源、低成本的个人智能体方案：你可以在自己的设备上运行，选择模型，也可以自行部署中继。项目希望与各地的开发者和使用者一起完善这些功能，让使用者自己掌握智能体。你可以提交 issue（问题或建议），也可以提交 PR（供项目维护者审阅的代码或文档修改）。
