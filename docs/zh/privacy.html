隐私 ​

这一页讲 nanoMuse 的各个应用——手机 App、网页版和桌面版、dsh 插件——以及 nanoMuse Cloud 怎么处理你的数据。它很短，因为它们对数据做的事很少。在要紧的地方，由你决定的只有一个开关：设置 → 数据控制。

一切都留在你的设备上 ​

智能体在 App 里面运行——在手机上，是 App 私有存储里的一个 Linux 根文件系统；在电脑上，是你装的那个运行时。对话、记忆、智能体写的文件、定时任务、技能和设置都存在那里，以及你挂载的那些自己选的文件夹里。没有任何分析统计、没有向我们发送的崩溃报告、没有任何形式的遥测。nanoMuse 唯一的服务器是下面说的那个可选的中继，没有它各个 App 也能完整使用。

哪些会离开设备 ​

  • 你的模型服务商。 消息、附带的图片和工具结果会发给你配置的模型端点（阿里云百炼、DeepSeek、OpenAI、OpenRouter、你自己的 vLLM 或 Ollama……），受那家服务商的条款约束，用的是你输入的 API key。key 只存在你的设备上。
  • nanoMuse Cloud，如果你登录了。 第一屏的「登录，免费开始」（或 设置 → nanoMuse Cloud）用手机号或邮箱加一个验证码给你注册，之后 App 把我们的中继当成一个模型服务商来用——免费，每个账号 ¥10 的模型用量（社区成员不限；每有一个新人用你的邀请码注册，你的额度加 ¥5，对方也加 ¥5），钱由开发者出；nanoMuse 是非营利的社区项目，从不收费。中继把你的消息转发给模型（阿里云百炼）。关于账号，它保存这些：你地址的加盐哈希；地址本身的加密副本，让运行中继的人能看出账号是谁的（单看数据库文件什么也看不出来）；一个打码的提示，比如 s***@example.com；发给这台设备的 key 的哈希；每次请求的类型、模型和 token 数；你的邀请码以及用过它的账号 id；还有——为了让你的各台设备显示同一个——智能体的名字和形象（用的是哪一张；如果是形象工作室里画的，还有它的五张小图）。每次登录、请求、时间线事件和设备，它还会记下请求来自的网络地址和客户端软件（User-Agent：Android App 及其版本、Windows、macOS 或 Linux 上的运行时、某个浏览器），账号则保留第一个和最后一个地址，以及最后一次出现的时间——运行中继的人在运营者页面上按账号、按地址看到这些，用来分辨「一个人开两个账号」和「两个人共用一个地址」，以及看清一个问题的轮廓。对话本身保存什么，由两个开关决定，下面接着讲。它收不到你的位置：各个 App 从不发送位置。地址旁边，运营者页面会显示这个地址属于哪个国家、省、市——在画页面的那一刻，从中继自己磁盘上一份离线的 ip2region 公开数据库里读出来，不问任何第三方，地点也不保存。退出登录会吊销 key；删除账号会删掉上述全部，地址也包括在内。中继的源码在仓库的 cloud/ 目录下，docs/cloud.md 讲怎么自己部署。用自己的 key 时，关于中继的这一切都不适用。
  • 项目网站（nanomuse.cn），如果你访问它。 它的 web 服务器保留七天访问日志，然后删除；一个脚本把日志变成按天的计数——看了哪些页面、多少访客、每个文件的下载次数、哪些网站链接过来。访客每天只计一次，用的是地址加浏览器字符串的哈希，盐是当天随机生成的、两天后丢弃；原始日志存活的那一周之外不保存任何地址，不和任何人共享，没有 cookie，也没有第三方统计。中继自己的运营者页面显示每天的登录数和账号数，来自上面说过的那些记录——没有为此多收集任何东西。
  • 数据控制——「帮助改进 nanoMuse 的 AI 模型」。 每个 App 的 设置 → 数据控制 里有一个开关。开着时，中继保留你和 nanoMuse Cloud 模型的聊天文本，用来训练社区自己的开放模型：你写的、模型答的、它选择的工具调用，连同模型、token 数，以及请求头里 App 的平台和语言。它不保留系统提示词（你的记忆、SOUL 和指令）、工具返回的内容、图片、音频或短视频——这些都换成一个标记——而且这些轮次只和你的账号 id 关联；用于训练的导出不带账号 id、地址或提示。在 cloud.nanomuse.cn 上，中继 0.9 之后创建的账号这个开关默认开着；之前就有的账号保持它们当初的选择。 开关旁边就写着这一点，自己部署的中继用 IMPROVE_DEFAULT 来选。随时可以关掉——从那之后不再保留任何东西——在同一页上点一下就能删掉此前保留的全部，删除账号也会一并删掉。额度和这个开关没有任何关系。
  • 同步的对话——登录后默认开启（中继 0.19 起）。 你对话的文本存在 nanoMuse Cloud 上，让你账号下的每台设备显示同样的聊天。文件和图片不上传。设置 → 数据控制 可以关掉它并删除已存的内容；在一台设备上删除一个聊天，所有设备上都会删除。除了你的设备，没有人能读它；运营者看到的是数量，不是文本。（确切说，存的是：每个对话的标题和由哪台设备发起，每条消息的角色、文本、时间和设备，以及附件的名字和大小——从不存文件，从不存图片，从不存工具返回的内容。发给另一台设备的聊天，或者这台设备替别的设备跑的聊天，不同步。中继每个账号最多保留 20 000 条消息，单条消息在 16 KB 处截断。细节在 docs/cloud.md。） 0.1.38 起默认只同步主要聊天：旁聊留在创建它的设备上，其他设备的旁聊也不会过来，除非你在那台设备上打开「同时同步旁聊」。你的一台设备正在回答时，其他设备会收到提示（「kwai 正在处理…」）；这条提示只经过中继的内存，从不保存，十分钟后就忘掉。
  • 网络，当智能体使用它时。 网页搜索、抓取页面、App 内浏览器、MCP 服务器和命令行工具会访问它们各自对应的网站和服务。智能体发出去的，就是你让它做的事。
  • 检查更新。 设置 → 关于（手机上是「检查更新」；桌面版在托盘；pipx/Docker 运行时每六小时一次，server.update_check = false 可以停掉）向 GitHub API 询问 nano-muse/nanoMuse 的最新版本。除了这个请求本身什么都不发，也不会自行下载任何东西。
  • 备份。 如果你备份到远端（SMB、WebDAV、SFTP、S3、FTP），备份会存到那里，用你选的密码加密。

权限 ​

每项权限都在某个功能需要时才请求，并且只用于那个功能：通知用于智能体的状态和提醒；无障碍用于操作其他 App 的屏幕，你打开之前它是关的；存储是你挂载的文件夹；麦克风用于语音输入；通讯录、日历和位置分别对应同名的工具，每个都要你授权之后才能调用。后台不读取任何东西。

智能体不问就能做什么 ​

做任何无法撤销的事之前——删你的文件、把消息或数据发出去、付款——智能体会停下来，弹一张卡片问你，在 shell 里、浏览器里和手机屏幕上都一样。你能从那张卡片上记住的内容分三档，设置 → 权限 → 记住的授权 列出你记住过的全部，按同样的方式分组，一行一条，点一下即可撤销：

  • 先做，再告诉你——安装软件。从不询问；智能体事后会说一声。
  • 先问；你可以记住——删除和发送。「本次对话都允许」或「对『X』总是允许」（一个文件夹、一个收件人、一个网站或 App）。
  • 最高一档：付款的那一刻问，每次都问——购买、下单、预订、交易、转账。没有「本次对话」这一项。「记住，下次在 X 里直接执行」是有的，只针对一个 App 或网站，并且在执行前要求验证你的锁屏（指纹、面容、PIN）；它排在权限页的最前面，每一笔靠它执行的付款都会在聊天里明说。

密码、验证码和卡号从不由智能体输入；这些界面交给你。命令里任何吓人的东西（抹掉一块磁盘、强推覆盖历史、下载后直接管道进 shell）每次都会问，也不能记住。你明确要买、要交易时，购物和交易没问题；不管怎么措辞，违法或有害的事都不会做——智能体会拒绝并说明原因。

反馈 ​

Bug 报告通过 设置 → 反馈 提到 GitHub Issues；报告里预填了 App 版本和设备型号，别的都没有。不要把 API key 或私人对话贴进 issue。

变更 ​

各个 App 的行为变了，这一页就跟着变；历史在仓库里。同样的文字在 nanomuse.cn/privacy，中英文都有。
