# nano-muse.github.io

The project homepage of [nanoMuse](https://github.com/nano-muse/nanoMuse), served at <https://nanomuse.cn/> — a server that pulls this repository every minute — and by GitHub Pages at <https://nano-muse.github.io/>. A push to `main` updates both within a minute.

One static page, `index.html` with `style.css` and `site.js`: the first screen is the demo — a frame of <https://demo.nanomuse.dev/> in its embed mode, which starts nothing until the visitor taps the phone; narrow screens get a still and a link instead — under a slim bar (Docs, Download, GitHub with the star count from GitHub's API, the language and theme switches). Below it: what nanoMuse is, the downloads of the current version, where to start in the docs, the last three releases. English and 简体中文 for every string (the switch keeps its choice in `localStorage`; without JavaScript both languages show), light and dark (saved, else the system's; set before first paint). No build step, no framework, no third-party scripts or fonts. `own-key/` and `privacy/` are the small pages the apps link to, `404.html` the page for an address that is not there, all with the same bar; `docs/` is the built documentation site, written by the release.
